## English

### What is EasyEdit?

EasyEdit is a hybrid terminal text editor that combines traditional insert mode with powerful command mode, inspired by Vim but designed for modern workflows.

### Key Features

- **Hybrid Input Mode**: Seamlessly switch between insert mode and command mode
- **Syntax Highlighting**: Support for 200+ programming languages via Chroma
- **Efficient Text Storage**: Gap Buffer implementation for fast large-file editing
- **Full Undo/Redo**: Never lose your work with comprehensive undo history
- **Cross-Platform**: Works on Windows, Linux, and macOS

## 中文

### 什么是 EasyEdit？

EasyEdit 是一个混合终端文本编辑器，结合了传统的插入模式和强大的命令模式，灵感来自 Vim，但为现代工作流程设计。

### 主要特性

- **混合输入模式**：在插入模式和命令模式之间无缝切换
- **语法高亮**：通过 Chroma 支持 200+ 种编程语言
- **高效文本存储**：Gap Buffer 实现，快速编辑大文件
- **完整撤销/重做**：全面的撤销历史，永不丢失工作
- **跨平台**：适用于 Windows、Linux 和 macOS
